# Origlyph v0.1.0-alpha.1

First public alpha — deterministic geometry foundation.

## Highlights

* Repository foundation: canonical `src/origlyph/` namespace, MIT-licensed, with CI workflow and a deterministic toolchain (pytest / Ruff / Pyright).
* Deterministic geometry foundation implemented in the Python standard library only — no runtime dependencies.
* 86 tests passing; Ruff PASS; Pyright PASS (0 errors, 0 warnings).

## Geometry Foundation

* Immutable, validated geometry value objects: `Point3D`, `Vector3D`, `Line3D`, `Plane3D`.
* Zero-vector semantics: a zero `Vector3D` is a valid mathematical value; normalization and orientation-requiring uses fail closed.
* Deterministic operations on the four primitives: distances, angles, projections, and closest-point computations.

## Units and Numerical Policy

* Canonical internal units: millimetres (length) and radians (angle), with dimensionally distinct `Length` and `Angle` value types.
* Explicit, fail-closed boundary conversion (mm/cm/m/inch, degree/radian); no implicit unit guessing.
* A single centralized computational tolerance policy for numerical robustness — explicitly not an engineering or manufacturing tolerance.

## Frames and Transforms

* Orthonormal right-handed coordinate frames, validated at construction (left-handed and non-orthonormal frames are rejected).
* Rigid transforms with a homogeneous 4x4 representation: identity, translation, rotation, composition, and inverse, applied to points and vectors.

## Known Limitations / Exclusions

This alpha does **not** yet provide:

* CAD parsing; STEP/IGES import
* Surfaces, solids, topology, Boolean operations
* Axis3D, Circle3D, Arc3D
* Intersection algorithms
* GD&T evaluation; datum selection
* Tolerance stack-up / dimensional-chain analysis
* Engineering acceptance/rejection decisions
* AI engineering decisions

No production-readiness, certification, ASME compliance, ISO compliance, or validated-manufacturing-capability claims are made.
