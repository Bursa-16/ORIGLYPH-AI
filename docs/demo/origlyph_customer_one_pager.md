# Origlyph AI

**Deterministic tolerance engineering. Traceable decisions. Reproducible results.**

---

## What It Is

Origlyph AI is a structured engineering platform for tolerance analysis and
traceable decision workflows. It replaces fragmented spreadsheet-based tolerance
work with a deterministic, auditable engineering environment where every input
is explicit, every calculation is reproducible, and every decision is traceable.

---

## Current Demo Capabilities

- 1D tolerance chain definition — contributors with nominal, tolerance, and direction
- Worst-case analysis — arithmetic stack of all contributor spans
- RSS / statistical analysis — quadratic combination of contributor variances
- Specification-aware evaluation — compare results against engineering limits
- Deterministic PASS / FAIL decision — explicit comparison, no probabilistic scoring
- Sensitivity analysis — quantified per-contributor impact ranking
- Tolerance budget analysis — actual span versus allowed span, per contributor
- Allocation plan input — target tolerance distribution across contributors
- Allocation validation — structural consistency check of the allocation plan
- Deterministic save and open — full project state persisted and restored exactly
- Reproducible project identity — SHA-256 configuration fingerprint per project state

---

## Typical Use Cases

- Tolerance stack analysis during design
- Design review preparation — deterministic evidence for engineering reviews
- Engineering change assessment — re-run analysis on modified chain
- Supplier or cross-functional tolerance discussions — shared project file
- Allocation review — distribute tolerance budget across contributing features
- Traceable tolerance decisions — each project state uniquely identified

---

## Why It Matters

- Replaces fragmented, manually maintained spreadsheets
- Delivers deterministic calculations — same inputs, same outputs, every time
- Makes tolerance decisions traceable and explainable to reviewers and stakeholders
- Exposes contributor sensitivity — directs design effort to the highest-impact features
- Supports repeatable engineering reviews with a consistent, structured workflow
- Separates authoritative engineering inputs from derived results — nothing is hidden

---

## Current Scope

Origlyph AI v0.4.0-alpha.7 is focused on **1D tolerance-engineering workflows**.

The current release supports:
- worst-case and RSS statistical analysis
- specification evaluation and decision
- sensitivity, budget, and allocation

The following are **planned for future releases** and are **not currently available**:
- CAD / STEP / B-Rep geometry import or binding
- Full GD&T evaluation and standards compliance
- Automatic tolerance optimisation or allocation generation
- Company-specific standards library integration
- Reporting and document export
- Audit, governance, and approval workflow UI
